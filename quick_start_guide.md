# ProjectKaro — Quick Start Guide

## What This Project Does

A **Next.js** marketing/landing site (React + TypeScript) with sections for CTA, FAQ, Header, Footer, Stats, Tech Stack, Testimonials, and a Start Project form. Uses nodemailer for contact/form handling.

## Prerequisites

- **Node.js 18+** (LTS recommended)
- npm or yarn

## Step-by-Step: Run on Any System

1. **Open a terminal** and go to the project folder:
   ```bash
   cd path/to/projectkaro
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in a browser:**  
   Go to **http://localhost:3000**.

## Other Commands

- **Production build:** `npm run build`
- **Start production server:** `npm run start`
- **Lint:** `npm run lint`
- **Type check:** `npm run type-check`
